# Memoria · Historia de la computadora

Sitio educativo en español sobre las cinco generaciones de la computadora.

- Página principal y cinco capítulos.
- Cinco fotografías o documentos reales por página, con créditos y licencias.
- Diseño adaptable a móvil y escritorio; texto e imagen alternados.
- Galería accesible con navegación por teclado y preguntas de repaso.
- Archivos HTML, CSS y JavaScript; funciona sin instalación.

## Abrir localmente

Abre `index.html` en un navegador. Las fotografías y fuentes se incluyen localmente.

## Fotografías y tipografías

Los autores, archivos originales y licencias de las imágenes se indican junto a cada imagen y en los créditos de cada página. Las imágenes se han optimizado en tamaño y formato para la web; la presentación puede adaptar el encuadre. Las licencias de las tipografías Newsreader y Manrope están incluidas en `assets/fonts/`.

## Publicación

GitHub Pages sirve la rama `main` desde la raíz del repositorio.
